# LiveSwitcher i18n Policy

## Decision

LiveSwitcher UI copy is **中文为主**. Use concise Chinese for operator-facing labels, actions, warnings, and help text. Keep common broadcast, audio, and file-format terms that Chinese operators already recognize.

## Keep These Terms

- BGM
- PPT
- HTML
- PPTX
- Keynote
- dB
- FTB
- LIVE

## Avoid

- Bilingual duplicate headers such as `Audio / 音频` or `Live Preflight / 现场检查`
- English-only primary actions when a short Chinese operator term exists
- Translating file formats, units, or established abbreviations into awkward Chinese

## Examples

Good:

- `音频`
- `叠层字幕`
- `节目单`
- `信号源`
- `紧急切黑`
- `检查`
- `FTB`

Avoid:

- `Audio / 音频`
- `Overlays / 叠层字幕`
- `Run Queue`
- `Sources`
- `Blackout / Stage black`
