# Current Main Console UI

This note tracks the current information architecture and the current public README screenshot.

- Run Desk is the primary operating surface for queue, program monitor, and Live Ops.
- Live Ops owns Output, Audio quick controls, BGM mini controls, and Modes.
- Audio / BGM Library is where mixer faders, routing strategy, and full BGM management live.
- Overlays / Overlay Composer is where lower third, countdown, and ticker drafts are prepared and sent live.

The public README screenshot is `docs/assets/readme/live-console-v0.5.0.png` and should show the current console with demo-only data. Older UI-matrix screenshots remain historical regression artifacts under `docs/assets/ui-matrix/`, but old readme screenshot slots should not be shown on the GitHub front page.
