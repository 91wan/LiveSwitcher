# Preflight Review Model Stage 8 Plan

## Goal

Converge the remaining Safety Cockpit / Preflight Popover duplication by sharing one pure model for preflight review filtering, ordering, and grouped display.

## Scope

### In scope

1. Add `PreflightReviewModel` and `PreflightReviewMode`.
2. Use the shared model in `PreflightPopoverView` for Needs Attention / All Checks.
3. Use the same model in `LiveSafetyCockpit` and `SafetyCockpitView` for the first-risk section.
4. Add model and source hygiene tests proving both surfaces use the shared model.

### Out of scope

- Merging the Safety Cockpit window and Preflight popover into one UI.
- Changing preflight check definitions.
- Changing support report export behavior.
- Broad i18n conversion.
